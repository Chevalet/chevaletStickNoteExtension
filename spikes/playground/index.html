Playground

Double-click anywhere on this page to stick a note there, then type. Everything is real: the note is written to IndexedDB under the normalized key for the URL shown in the bar above.

What to try

Reload the page. The notes come back in the same places. They are not in the cache and not in localStorage — they are in the extension's own IndexedDB, which is the store that survives clearing browsing data.

Switch to “Same article, shared link”. The notes are still there: the ?utm_source is stripped before the key is computed. Same for the http + www + trailing-slash version — all four spellings are one page. Now switch to “A different article” and they are correctly gone.

Switch between the two YouTube videos. Notes follow ?v= and ignore ?t=, so a note on a video stays on that video and does not leak onto every other video.

Switch between the two SPA routes. #/inbox and #/settings are different pages, because a #/ fragment is a route. A plain #section fragment is not, and would be ignored.

Scroll. A note stays with the paragraph it was dropped on, because its position is stored in document coordinates, not viewport coordinates.

Drag one, then reload. Position is saved 250 ms after you let go — the same debounce the extension uses so that typing never floods the database.

Delete one with the × button. It goes to the trash rather than being destroyed, and a restore button appears in the bar above.

Keyboard

Click a note once to focus it (do not click into the text), then: → move 1px · Shift+arrow 10px · Ctrl+arrow 25px · Alt+arrow resize · Enter edit · Esc stop editing · D draw · C next colour · L lock · M collapse · Z undo last stroke · Del delete.

The toolbar in each note's header does the same things: pen, colour, lock, collapse, delete.

Filler, so there is something to scroll past

A photocopier degrades an image a little every generation. Contrast climbs, midtones collapse into pure black and white, and dust on the platen becomes part of the artwork. Zine makers leaned into it: if the third-generation copy looked rougher, you made a fourth.

That is the look this extension is going for — high-contrast ink on saturated stock, halftone dots coarse enough to see, a hard unblurred drop shadow, and edges that were torn rather than cut. The constraint is that none of it may cost anything per frame.

The tear is a path generated once from a seeded pseudo-random number generator keyed on the note's id, so it is identical on every reload and on every machine. The grain is a single tile shared by every note. The corner curl is five pre-baked paths cross-faded by opacity. While a note is moving, only transform and opacity change.

Keep scrolling and drop a note down here, then go back to the top and return. It should be exactly where you left it.
